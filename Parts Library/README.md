# Parts Library

Parts sourced from project drawing packages (HM / HO) and physical photo inventory (May 2026).

**40 parts total** across Phoenix Contact, Connectwell, Eaton, Advantech, Cisco, Antaira, NETGEAR, PULS, Mean Well, DEHN, and enclosure inventory.

Each part folder contains:
- `README.md` — description, specs, and links
- `links.html` — clickable product/download buttons (open in browser)
- `info.txt` — plain-text record for scripts / automation
- `image.jpg` — 1500×1500 px product image

> **Images marked as placeholders** can be refreshed by running `scrape_images.py` once `phoenixcontact.com` is added to the network allowlist (Settings → Capabilities → Network access).

## Library conventions

- Folder names: `{Description}_{PartNumber}` for confirmed parts
- `parts_index.csv` — flat index of all parts, ready for automation
- `scrape_images.py` — downloads Phoenix Contact images from eshop CDN (requires network access to `phoenixcontact.com`)
- Phoenix Contact URL pattern: `https://www.phoenixcontact.com/en-us/products/{slug}-{part_number}`
- Phoenix Contact PDF: `https://www.phoenixcontact.com/us/products/{part_number}/pdf`
