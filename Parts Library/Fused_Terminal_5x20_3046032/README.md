# 3046032 — UT 4-HESI (5X20)

**Phoenix Contact part number:** `3046032`
**Product name:** UT 4-HESI (5X20)
**Category:** Fuse modular terminal block

## Description
Fuse modular terminal block for 5 × 20 mm glass/ceramic fuses, 6.3 A, 500 V. Screw connection, polyamide insulator. Black with safety lever, test connection on both sides.

## Key specifications
- Fuse type: 5x20 mm G
- Nominal voltage: 500 V
- Nominal current: 6.3 A
- Rated cross section: 4 mm² (AWG 26–10)
- Mounting: NS 35/7,5 or 35/15
- Color: black
