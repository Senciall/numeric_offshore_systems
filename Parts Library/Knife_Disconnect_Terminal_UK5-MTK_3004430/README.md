# 3004430 — UK 5-MTK

**Part number:** `3004430`
**Product name:** UK 5-MTK
**Manufacturer:** Phoenix Contact
**Category:** Knife-disconnect terminal block

## Description
Knife-disconnect terminal block (UK series). 2.5 mm², 500 V, 16 A. Gray housing with orange disconnect lever. Allows circuit isolation by rotating the orange lever to break the connection.

## Key specifications
Nominal voltage: 500 V; Nominal current: 16 A; Rated cross section: 2.5 mm²; Color: gray housing, orange lever; Mounting: NS 35/7.5 or 35/15; IEC 60947-7-1
