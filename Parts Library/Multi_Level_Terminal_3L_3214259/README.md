# 3214259 — UT 2,5-3L

**Phoenix Contact part number:** `3214259`
**Product name:** UT 2,5-3L
**Category:** Multi-level terminal block (3 levels)

## Description
Multi-level (3-level) feed-through terminal block. 500 V, 19 A, 2.5 mm² screw connection. 5.2 mm wide, gray. Each level has its own function shaft.

## Key specifications
- Levels: 3
- Nominal voltage: 500 V
- Nominal current: 19 A
- Rated cross section: 2.5 mm² (0.14–4 mm²)
- Width: 5.2 mm
- Mounting: NS 35/7,5 or 35/15
- Color: gray
