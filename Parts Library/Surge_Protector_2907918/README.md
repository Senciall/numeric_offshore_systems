# 2907918 — PLT-SEC-T3-120-FM-UT

**Phoenix Contact part number:** `2907918`
**Product name:** PLT-SEC-T3-120-FM-UT
**Category:** Surge protection device (Type 3)

## Description
Type 2/3 surge protection device, plug-in base + protective plug with integrated status indicator and remote signaling. For single-phase 120 V power supply networks. DIN rail mount.

## Key specifications
- Nominal voltage: 120 V AC/DC
- MCOV: 150 V
- Imax: 10 kA
- Conductors: L/N/PE
- Width: 17.7 mm
- Mounting: NS 35 DIN rail
- IP20
- Status indicator + remote signaling
