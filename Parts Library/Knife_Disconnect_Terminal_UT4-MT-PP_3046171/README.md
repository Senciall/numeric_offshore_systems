# 3046171 — UT 4-MT-P/P

## Description
Knife-disconnect terminal block with test sockets on both sides (push-in test probe connection). 4 mm², 500 V. Gray housing. Allows circuit isolation and in-circuit measurement without disconnecting wiring.

## Key specifications
Nominal voltage: 500 V; Rated cross section: 4 mm² (AWG 26–10); UL: 600 V / 16 A (300 V 16 A); Connection: screw; Test sockets: push-in both sides (-P/P); Color: gray; IEC 60947-7-1
