# 3046139 — UT 4-MT

**Phoenix Contact part number:** `3046139`
**Product name:** UT 4-MT
**Category:** Knife-disconnect terminal block

## Description
Knife-disconnect terminal block, 500 V nominal, 20 A thermal continuous current. Screw connection, 6.2 mm wide, gray. For testing/isolating circuits.

## Key specifications
- Nominal voltage: 500 V
- Continuous current: 20 A
- Rated cross section: 4 mm² (AWG 26–10)
- Width: 6.2 mm
- Length: 57.8 mm
- Mounting: NS 35/7,5 or 35/15
- Color: gray
