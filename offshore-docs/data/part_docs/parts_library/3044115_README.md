# 3044115 — UT 6

**Phoenix Contact part number:** `3044115`
**Product name:** UT 6
**Category:** Feed-through terminal block

## Description
Feed-through terminal block (CLIPLINE complete UT series). 1000 V nominal, 41 A nominal, screw connection, 6 mm² rated cross section. Gray housing (older production runs may appear cream/white — same part number).

## Key specifications
Nominal voltage: 1000 V; Nominal current: 41 A; Rated cross section: 6 mm² (AWG 22–8); Width: 8 mm; Height: 47 mm; Mounting: NS 35/7.5 or 35/15; Color: gray; IEC 60947-7-1; UL94 V0
