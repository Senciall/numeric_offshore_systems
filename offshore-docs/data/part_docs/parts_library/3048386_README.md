# 3048386 — UK 10,3-HESI N

**Phoenix Contact part number:** `3048386`
**Product name:** UK 10,3-HESI N
**Category:** Fuse holder (10×38 mm fuses)

## Description
Fuse holder for 10 × 38 mm fuse-links (per IEC 60269-2). 690 V AC, 32 A, single-pole disconnect feed-through. Screw connection, black.

## Key specifications
- Fuse: 10×38 mm ceramic
- Nominal voltage: 690 V AC
- Nominal current: 32 A
- Rated cross section: 16 mm² (1–16 mm²)
- Mounting: NS 35/7,5 or 35/15
- Color: black
