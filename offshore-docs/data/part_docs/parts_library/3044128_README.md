# 3044128 — UT 4-PE

**Phoenix Contact part number:** `3044128`
**Product name:** UT 4-PE
**Category:** Ground/protective conductor terminal block

## Description
Protective conductor (ground) terminal block, UT 4-PE. Bonds directly to DIN rail for low-resistance grounding. Screw connection, green-yellow.

## Key specifications
- Cross section: 0.14–6 mm² (AWG 26–10)
- Current: 38 A
- Rated surge: 8 kV
- Width: 6.2 mm
- Length: 47.7 mm
- Mounting: NS 35/7,5 or 35/15
- Color: green-yellow
