# 3046401 — UT 6-HESI (6,3X32)

**Phoenix Contact part number:** `3046401`
**Product name:** UT 6-HESI (6,3X32)
**Category:** Fuse modular terminal block

## Description
Fuse modular terminal block for 6.3 × 32 mm glass fuses, 10 A, 630 V. Screw connection M4, polyamide. Black with safety lever.

## Key specifications
- Fuse type: 6.3 × 32 mm G
- Nominal voltage: 630 V
- Nominal current: 10 A
- Rated cross section: 6 mm² (0.2–10 mm²)
- Surge: 6 kV
- Max dissipation: 1.6 W
- Color: black
- Pack: 50 pc
