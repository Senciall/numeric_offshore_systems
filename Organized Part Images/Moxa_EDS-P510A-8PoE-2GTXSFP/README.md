# EDS-P510A-8PoE-2GTXSFP - Moxa EDS-P510A-8PoE-2GTXSFP Managed PoE+ Ethernet Switch

**Part number:** `EDS-P510A-8PoE-2GTXSFP`  
**Manufacturer:** Moxa  
**Category:** Industrial managed PoE+ Ethernet switch (10-port)  
**Verified:** Yes (links verified May 2026)

## Description
Moxa EDS-P510A series Layer 2 managed industrial Ethernet switch with 8x 10/100BaseT(X) PoE+ ports and 2x combo Gigabit (GbE TX or SFP) uplink ports. IEEE 802.3af/at PoE+ output up to 30 W per port. Supports redundant Turbo Ring/Turbo Chain, IEEE 1588v2 PTP, NETCONF/SNMPv3, and DIN-rail or rack mount.

## Key specifications
Ports: 8x 10/100 PoE+ (30 W/port) + 2x combo Gigabit TX/SFP; PoE budget: 240 W max; Power: 46-57 V DC (PoE+); IP30 housing; Operating temp: -10 to +60 C (standard) or -40 to +75 C (T-model)
