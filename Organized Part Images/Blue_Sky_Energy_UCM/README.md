# UCM - Blue Sky Energy / SunForge Universal Communication Module (UCM)

**Part number:** `UCM`  
**Manufacturer:** SunForge LLC (formerly Blue Sky Energy)  
**Category:** Communication / network interface module  
**Verified:** Yes (links verified May 2026)

## Description
Universal Communication Module that adds network connectivity to Blue Sky Energy / SunForge charge controllers. Bridges the IPN bus to RS-232 / USB / Ethernet for remote monitoring and configuration. Used with Solar Boost iL/iX series MPPT charge controllers and IPN ProRemote.

## Key specifications
Interfaces: IPN bus to RS-232 / USB / Ethernet (model dependent); Compatible with Solar Boost iL/iX series and IPN ProRemote; DIN/wall mount
