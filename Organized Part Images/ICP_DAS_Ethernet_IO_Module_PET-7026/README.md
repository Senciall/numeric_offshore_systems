# PET-7026 - ICP DAS PET-7026 PoE Ethernet I/O Module

**Part number:** `PET-7026`  
**Manufacturer:** ICP DAS  
**Category:** PoE Ethernet (Modbus TCP) mixed I/O module  
**Verified:** Yes (links verified May 2026)

## Description
ICP DAS PET-7026 industrial PoE Ethernet I/O module with mixed analog and digital I/O: 6 differential analog inputs (16-bit), 2 analog outputs (optional), 2 digital inputs, and 2 digital outputs. Modbus TCP server, web-configurable, IEEE 802.3af PoE-powered, DIN-rail mount.

## Key specifications
AI: 6 ch differential, 16-bit; AO: 2 ch (option); DI: 2 ch; DO: 2 ch; Communication: Ethernet 10/100 Modbus TCP; Power: 802.3af PoE or +12 to +48 V DC; Mount: DIN rail
